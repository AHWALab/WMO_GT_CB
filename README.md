# WMO Guatemala Capacity Building Workshop

Este repositorio contiene los materiales desarrollados para los talleres de capacitación en Guatemala sobre **modelación hidrológica y pronóstico de inundaciones repentinas**, utilizando **EF5 (Ensemble Framework for Flash Flood Forecasting)** y **TITO**.

Los materiales del taller están organizados en dos ramas (*branches*) principales, correspondientes a los dos días de capacitación.

## Ramas del taller

### Día 1 — EF5

**Branch:** `Day1_EF5`

El primer día está enfocado en el uso del modelo hidrológico **EF5** para Guatemala.

Esta rama contiene los archivos, datos y configuraciones necesarios para ejecutar EF5 mediante **Docker**, incluyendo configuraciones del modelo a resoluciones de **900 m y 90 m**. Los ejercicios permiten explorar la configuración y ejecución del modelo hidrológico, así como analizar las salidas generadas para diferentes dominios y estaciones.

**Acceder a la rama:**  
https://github.com/AHWALab/WMO_GT_CB/tree/Day1_EF5

Las instrucciones detalladas para instalar, configurar y ejecutar EF5 se encuentran en el README de esta rama.

---

### Día 2 — TITO Guatemala

**Branch:** `Day2_TITO_Guatemala`

El segundo día está enfocado en **TITO** y su aplicación para el pronóstico hidrológico en Guatemala.

Esta rama contiene los materiales y ejercicios utilizados durante el taller para explorar el sistema TITO, incluyendo el procesamiento de información hidrometeorológica y la generación y análisis de pronósticos hidrológicos para Guatemala.

**Acceder a la rama:**  
https://github.com/AHWALab/WMO_GT_CB/tree/Day2_TITO_Guatemala

Las instrucciones y ejercicios específicos para TITO se encuentran en el README de esta rama.

---
