STREAM-Sat ensemble QPE generation over Caribbean and Comoros main code 

This repo is created to generate STREAM-Sat at real-time. Calls upstream STREAM-Sat (KaidiWisc/STREAM-Sat) at the repository root
with ``tres=0.5`` for half-hourly resolution. More info is available at:
Li et al. (2023) doi:10.1109/tgrs.2023.3235270 
Hartke et al. (2022) https://doi.org/10.1029/2021WR031650
Peng et al. (2025) https://doi.org/10.1029/2023WR036756 

Use GFS 850 hPa u/v fields to generate motion vectors at real time.
