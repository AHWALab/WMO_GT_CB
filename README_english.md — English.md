# WMO Guatemala Capacity Building Workshop

This repository contains the materials developed for the capacity-building workshops in Guatemala on **hydrologic modeling and flash flood forecasting**, using **EF5 (Ensemble Framework for Flash Flood Forecasting)** and **TITO**.

The workshop materials are organized into two main branches corresponding to the two training days.

## Workshop Branches

### Day 1 — EF5

**Branch:** `Day1_EF5`

The first day focuses on using the **EF5 hydrologic model** for Guatemala.

This branch contains the files, data, and configurations required to run EF5 using **Docker**, including model configurations at **900 m and 90 m resolutions**. The exercises introduce the configuration and execution of the hydrologic model and the analysis of model outputs for different domains and gauge locations.

**Access the branch:**  
https://github.com/AHWALab/WMO_GT_CB/tree/Day1_EF5

Detailed instructions for installing, configuring, and running EF5 are provided in the README within this branch.

---

### Day 2 — TITO Guatemala

**Branch:** `Day2_TITO_Guatemala`

The second day focuses on **TITO** and its application to hydrologic forecasting in Guatemala.

This branch contains the materials and exercises used during the workshop to explore the TITO system, including the processing of hydrometeorological information and the generation and analysis of hydrologic forecasts for Guatemala.

**Access the branch:**  
https://github.com/AHWALab/WMO_GT_CB/tree/Day2_TITO_Guatemala

Detailed instructions and exercises for TITO are provided in the README within this branch.

---
